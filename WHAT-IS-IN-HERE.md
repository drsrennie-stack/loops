# Anatomy Loops, push package

Built 2026-08-10.

## Files

- index.html
  The working app, one file, nothing else to upload. Replace the index.html
  in your repo with this one. Your existing images/ folder stays exactly
  where it is; this file expects it at images/ next to itself.

- preview-app-look.html
  The app-look mockup, optional. Push it if you want to click around the
  redesign on the live site at /preview-app-look.html without touching the
  main page. Delete it whenever.

- .nojekyll
  Keeps GitHub Pages from running Jekyll. Your repo already has one; this
  copy is here so nothing breaks if it ever goes missing.

## What index.html now includes

- Modules 1 to 5 from the Fall 2026 schedule, body system filter within each
- Confidence rating before every answer, blanks locked until they pick
- Red flags: high confidence misses tagged, own dashboard section and drill
- Student override buttons: I got it right / Right structure, I misspelled it
- Two labelled blanks on the quadrant stations, letter and name both accepted
- 43 list and description stations are self marked, never string graded
- Combine: Play everything shown, or hand pick loops and run them together
- BlueLink thank you fires on every run containing cadaver or specimen loops
- Weakness dashboard: strong, developing, weak, red flags, not started
- Pronunciation: the speak button from the original, on every answer view
- Footer: Dr. Sharilyn Rennie, BIO 004 Human Anatomy, Solano College
- Three figure logo header linking to the course home

## What it does not touch

Student progress lives in each student's own browser under the key
loopsEngine_v1. No names, no accounts, nothing sent anywhere. Replacing
index.html does not erase anyone's progress.
